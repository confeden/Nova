# nova-rs

Ядро Nova на Rust. Заменяет логические подсистемы монолита `nova.pyw`
(27 016 строк) набором крейтов с тестами.

**Статус: ядро реализовано, приложение — нет.** Здесь нет GUI, драйверов и
сетевого ввода-вывода. Всё, что есть, — чистые детерминированные конечные
автоматы и алгоритмы, которые в Python были размазаны по монолиту и не покрыты
тестами. Python-приложение продолжает работать и остаётся тем, что запускает
пользователь.

## Крейты

| Крейт | Назначение | Тестов |
|---|---|---|
| `nova-core` | Общий словарь: домены, группы, транспорты, вердикты, сигнатуры блокировок | 12 |
| `nova-learn` | Самообучение выбора стратегий: Thompson sampling с забыванием, детектор смены режима, холодный старт | 28 |
| `nova-cloudflare` | Определение Cloudflare-сайтов в рантайме и политика их маршрутизации | 25 |
| `nova-health` | Здоровье транспортов и автоматический fallback с гистерезисом | 23 |
| `nova-zapret` | Backend-независимое представление стратегий DPI-обхода + эмиттер для zapret v1 | 18 |

Всего 106 тестов, все проходят.

## Сборка

```bash
cargo test --workspace
```

Требуется Rust 1.90+ (проверено на 1.95.0, `x86_64-pc-windows-msvc`).

## Принципы

**Никакого ввода-вывода в логике.** Обучение, определение Cloudflare и failover —
чистые функции от наблюдений и монотонного счётчика времени. Поэтому весь путь
отказа WARP тестируется без сети, а тесты выполняются за 0.2 секунды.

**Время — счётчик, а не часы.** Везде используется `nova_core::Seconds` — секунды
аптайма процесса. Настенные часы непригодны для затухания весов: ноутбук,
проснувшийся после сна, обнулил бы всё разом.

**Ошибка, за которую мы не отвечаем, не записывается на наш счёт.**
`BlockSignature::is_not_our_fault` отделяет «сайт лежит» от «нас блокируют».
Без этого разделения обучение медленно травит собственную лучшую стратегию во
время чужой аварии.

**Неизвестное сохраняется дословно.** Опции zapret, которых нет в IR, проходят
через `Strategy::passthrough` и возвращаются в вывод без изменений.

## Что дальше

Крейты ввода-вывода, которых ещё нет: `nova-probe` (сетевые пробы и
