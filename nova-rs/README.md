# nova-rs

Ядро Nova на Rust. Заменяет логические подсистемы монолита `nova.pyw`
(27 016 строк) набором крейтов с тестами.

**Статус: ядро реализовано, приложение — нет.** Здесь нет GUI, драйверов и
сетевого ввода-вывода. Всё, что есть, — чистые детерминированные конечные
автоматы и алгоритмы, которые в Python были размазаны по монолиту и не покрыты
тестами. Python-приложение продолжает работать и остаётся тем, что запускает
пользователь.

## Крейты

| Крейт | Назначение | Тестов |
|---|---|---|
| `nova-core` | Общий словарь: домены, группы, транспорты, вердикты, сигнатуры блокировок | 19 |
| `nova-learn` | Самообучение выбора стратегий и формы ClientHello: Thompson sampling с забыванием, детектор смены режима, холодный старт | 66 |
| `nova-cloudflare` | Определение Cloudflare-сайтов в рантайме и политика их маршрутизации | 26 |
| `nova-health` | Здоровье транспортов и автоматический fallback с гистерезисом | 29 |
| `nova-probe` | Классификация отказа по фазе, которая его вызвала | 19 |
| `nova-tls` | Чтение и формирование ClientHello: измерение JA4, браузерные профили | 20 |
| `nova-zapret` | Backend-независимое представление стратегий DPI-обхода + эмиттер для zapret v1 | 41 |

Всего 220 тестов, все проходят. Ещё 15 — за фичей `shape`, которая добавляет
собственно отправку сформированного ClientHello и требует BoringSSL:

```bash
cargo test -p nova-tls --features shape
```

Она выключена по умолчанию не из осторожности, а из соображения доступности:
измерительная половина `nova-tls` — чистый Rust и собирается везде, а BoringSSL
тянет за собой cmake, MSVC, NASM и LLVM. Машина, которой нужно только читать
отпечатки, не должна собирать для этого криптобиблиотеку.

## Сборка

```bash
cargo test --workspace
```

Требуется Rust 1.90+ (проверено на 1.95.0, `x86_64-pc-windows-msvc`).

## Принципы

**Никакого ввода-вывода в логике.** Обучение, определение Cloudflare и failover —
чистые функции от наблюдений и монотонного счётчика времени. Поэтому весь путь
отказа WARP тестируется без сети, а тесты выполняются за 0.2 секунды.

**Время — счётчик, а не часы.** Везде используется `nova_core::Seconds` — секунды
аптайма процесса. Настенные часы непригодны для затухания весов: ноутбук,
проснувшийся после сна, обнулил бы всё разом.

**Ошибка, за которую мы не отвечаем, не записывается на наш счёт.**
`BlockSignature::is_not_our_fault` отделяет «сайт лежит» от «нас блокируют».
Без этого разделения обучение медленно травит собственную лучшую стратегию во
время чужой аварии.

**Неизвестное сохраняется дословно.** Опции zapret, которых нет в IR, проходят
через `Strategy::passthrough` и возвращаются в вывод без изменений.

## Что дальше

`nova-probe` пока содержит только классификатор — чистую функцию от наблюдений
к вердикту. Сами сетевые пробы ещё живут в Python.

Крейтов ввода-вывода по-прежнему нет: `nova-config` (загрузка и атомарная
запись конфигов), `nova-routing` (генерация PAC, применение решений), `nova-app`
(GUI и супервизор процессов). См. [`docs/REFACTOR.md`](../docs/REFACTOR.md).

Отдельно ждёт своей очереди `nova-tls` — управляемая форма ClientHello на
BoringSSL. Пока её нет, `BlockSignature::TunnelHandshakeIgnored` показывает
проблему, но переключать нечего: профиль ровно один. См.
[`docs/adr/0003-tunnel-phases.md`](../docs/adr/0003-tunnel-phases.md).
