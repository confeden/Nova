# 🌌 Nova Linux

Адаптивная система обхода фильтрации трафика и маршрутизации для **Linux** с аутентичным интерфейсом оригинальной Nova.

---

## ⚡ О проекте

**Nova Linux** — это переосмысление Windows-версии [Nova](https://github.com/confeden/Nova) на базе нативных сетевых возможностей ядра Linux.

В отличие от Windows, где приложению требуются сторонние драйверы ядра (`WinDivert`, `NovaWFP.sys`), в Linux вся система построена на штатных, сверхбыстрых и стабильных технологиях ядра: **TProxy, nftables, sing-box и ByeDPI**.

### Ключевые возможности:
* **Zero-Config:** Работает сразу после установки без ручного поиска серверов и подписок.
* **Раздельная маршрутизация (Smart Split-Routing):**
  * 📺 **YouTube:** Высокая скорость и 4K за счет обхода DPI (fake/split) без проксирования тяжелого трафика.
  * 💬 **Discord:** Работа текстовых каналов и голосовых звонков (UDP).
  * ✈️ **Telegram:** Прозрачный WebSocket-релей через официальные узлы и Cloudflare.
  * 🧠 **AI (ChatGPT, Claude, Gemini):** Автоматическое направление запросов через чистые гео-локации.
  * 🇷🇺 **Российские сервисы:** Напрямую без задержек и изменений.
* **DPI Auto-Tuning:** Алгоритм (Thompson sampling) непрерывно анализирует качество связи и подбирает рабочие стратегии искажения пакетов при изменении правил ТСПУ.
* **Аутентичный UI в стиле Nova:** Компактный плавающий виджет на **Tauri v2** с неоновыми светящимися «пилюлями» статусов, плавным перетаскиванием и панелью журнала событий.
* **Zero Telemetry:** Никаких внешних логов или аналитики — все данные и обучение остаются исключительно на вашей машине.

## 🏗 Архитектура

Приложение строго разделено на системную службу и пользовательский интерфейс в соответствии со стандартами безопасности Linux:

```
┌─────────────────────────────────────────────────────────────┐
│                   nova-gui (Tauri v2)                       │
│    Компактный плавающий виджет (~360×280 px), трей          │
└──────────────────────────────┬──────────────────────────────┘
                               │  UNIX Domain Socket (/run/nova/novad.sock)
┌──────────────────────────────▼──────────────────────────────┐
│                    novad (Системный демон)                  │
│    • DpiTuner (Thompson sampling / CUSUM)                   │
│    • Управление nftables (TProxy) с безопасным откатом       │
│    • Контроль sing-box (TUN/TProxy) и ByeDPI (ciadpi SOCKS) │
└─────────────────────────────────────────────────────────────┘
```

## 🚀 Быстрый старт

### Установка зависимостей и запуск:

```bash
# 1. Клонирование репозитория
git clone https://github.com/your-username/nova_linux.git
cd nova_linux

# 2. Установка зависимостей и демона
sudo bash scripts/install.sh

# 3. Запуск графического интерфейса
nova
```

## 🛠 Сборка из исходников

Требования:
* **Rust 1.80+** (`cargo`)
* **Node.js 20+**
* Системные библиотеки: `libwebkit2gtk-4.1-dev`, `libappindicator3-dev`, `nftables`

```bash
# Сборка демона novad
cargo build --release -p novad

# Сборка интерфейса nova-gui
cargo build --release -p nova-gui
```
