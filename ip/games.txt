# version: 1.40.1
# Nova PC - Games routing list (Path of Exile endpoints reached by IP)
#
# The WinDivert redirect claims these IPs without process metadata, on the ports
# in GAMES_STATIC_FALLBACK_PORTS (windivert_redirect.py). That path exists
# because process attribution loses a race on a process's very first connection
# - which is exactly the connection the launcher makes.
#
# IMPORTANT: this fallback is NOT process-scoped. Any process talking to an
# address on this list, on one of those ports, goes through WARP. Only add an
# address that belongs to GGG alone.
#
# --- Measured live 2026-08-23 through the running redirect ---
# patch.pathofexile.com resolves (via a per-deployment pacloudflare.com CNAME,
# so this WILL drift again) to 172.65.204.172. Its protocol is raw TCP on port
# 12995, NOT HTTPS: send 01 04 and the server answers 181 bytes naming the
# content CDN (https://patch.poecdn.com/<version>/). Confirmed working both
# direct (35 ms) and through WARP (137 ms).
#
# Port 443 on 172.65.204.172 accepts TCP and then drops the connection right
# after the ClientHello - through WARP and through Opera alike. This is NOT the
# SNI-based DPI reset an earlier note here claimed: Cloudflare Spectrum simply
# exposes no TLS service on that address. Do not read a 443 failure here as
# censorship.
#
# The content CDN (patch.poecdn.com -> 2.17.144.x, Akamai) is reachable
# directly and needs no entry here, and must not get one: those addresses are
# shared Akamai anycast and this fallback would drag unrelated traffic to WARP.
#
# What actually broke Path of Exile was Nova itself, not the network. The
# redirect hijacked a connection whose SYN it had missed, into a proxy that
# never saw the handshake (ROADMAP G36), and this fallback registered no return
# path at all, so its own redirects hung in SYN-SENT (G35). Both fixed - so
# re-measure before blaming this list again.
#
# 94.131.191.1 is intentionally EXCLUDED: WARP times out / blocks it, so it only
# causes the patch to fail.
172.65.204.172          # patch.pathofexile.com (Cloudflare Spectrum, ports 12995/20481)

# the SurfEasy discover API). The earlier capture attributed Nova's own
